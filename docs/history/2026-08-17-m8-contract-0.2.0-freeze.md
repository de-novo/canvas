# M8 contract and canonical 0.2.0 freeze

**Date:** 2026-08-17
**Status:** decision recorded

## Context

After the review-hardening pass, three follow-ups were open: LICENSE, a
possible `0.3.0` bump, and an M8 contract. The product owner decided:

- LICENSE waits until the public-release pass;
- the schema version stays `0.2.0`;
- M8 needs a written contract before more diagram work.

## Changes

- [M0 Product Contract](../m0-product-contract.md) now names `edge`,
  `text`, `html`, and `mesh` as frozen `0.2.0` built-ins. New built-in
  kinds after this freeze require a migration or a plugin node.
- [M8 Diagram Contract](../m8-diagram-contract.md) freezes edge/port/path
  rules (`routing === "orthogonal"` then `curve` + `curveOffset`), HTML
  overlay (host `HTMLElement` or `textContent`, never runtime
  `innerHTML`), graph paste/delete/ungroup, connector tool, camera
  helpers, and explicit non-goals (not Figma, not foreignObject, not
  3D edges).
- Public API contract lists `createConnectorTool` and the 2D camera
  helpers.
- Project status Next no longer asks for a `0.3.0` bump or treats
  LICENSE as the immediate next coding task.

## Verification

Documentation-only. No runtime commands were required.

## Residual risk

`routing: "curved"` remains a stored no-op. The contract forbids treating
it as a third algorithm; existing documents that set it still parse.

M8 is not verified. The contract's acceptance list has not been run as a
milestone pass.

## Next action

Implement any remaining contract gaps (dead `routing: "curved"` writes,
diagram verification named in the contract) or stop adding 2D node kinds.
